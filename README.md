# Rightmove plc Investment Analysis

Independent investment analysis of Rightmove plc (LSE: RMV), combining historical financial analysis, operating KPI decomposition, financial forecasting and DCF valuation.

## Methodology

Five years of Rightmove financial and operating data were collected from company annual reports and analysed using Python. The project covers historical KPI decomposition, financial forecasting, DCF valuation, sensitivity analysis, scenario analysis and reverse DCF.

## Key Findings

- Reference share price: **£4.99**
- Base-case DCF: **£6.40**
- Consensus-adjusted DCF: **£6.37**
- Implied upside: **27.6%**
- Bear / Base / Bull: **£4.25 / £6.40 / £8.87**
- Historical revenue CAGR (2021–2025): **8.67%**
- Agency ARPA CAGR: **7.28%**
- Agency branch CAGR: **0.42%**

## Analysis

The central finding is that Rightmove's historical growth has been driven primarily by advertiser monetisation rather than customer expansion. Agency ARPA grew substantially faster than Agency branch numbers between 2021 and 2025.

The project tests the durability of this model through financial forecasting, DCF valuation, sensitivity analysis, reverse DCF and bear/base/bull scenarios.

## Tools and Methods

**Python:** pandas, NumPy, Matplotlib, SciPy

**Financial analysis:** financial statement analysis, operating KPI analysis, forecasting, DCF valuation, sensitivity analysis, scenario analysis and reverse DCF.
